# Requisitos iniciais — nestjs-api

Backend Node.js/NestJS de laboratório para rastreamento de veículos, integrações de mapas e mensageria.

- RF-01: Inicializar componentes necessários e expor fluxo principal.
- RF-02: Validar entradas, falhas de recursos e contratos existentes.
- RF-03: Preservar integração com clientes/serviços documentados.
- RNF-01: Dependências e configuração reproduzíveis.
- RNF-02: Não publicar credenciais ou dados pessoais.
- RNF-03: Testes unitários, integração e construção da aplicação.

Os requisitos são hipóteses para validação, não prova de implementação. O README antigo dizia Django, mas o manifesto comprova NestJS. O repositório inclui node_modules e dist rastreados: limpar em PR separado após build controlado.
